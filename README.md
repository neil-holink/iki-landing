# i.ki — Landing Page Prototype

A coded prototype of the **i.ki** landing page — an AI smart-link & QR platform (dub.co-style).

Pure static **HTML / CSS / JS** (no build step). Just open `index.html`.

## Highlights
- AI "Suggest & Shorten" hero with an interactive shorten flow
- Hero variants: **default** = ranked AI-name picker (+ a custom-name option); add **`?hero=a`** to the URL for the single-name + alternative-chips variant
- Interactive WebGL globe (cobe), animated product preview, smart-router demo, pricing, testimonials

## Run locally
```bash
python -m http.server 5185
# then open http://localhost:5185
```

Brand: orange `#ff5a1f`, ink `#171717`, Inter + Geist Mono.
